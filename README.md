\# Mon premier projet



Portfolio de petits projets Python réalisés pendant ma L3 mathématiques, dans l'optique d'un master en IA/data science.



\## Projets inclus



\- \*\*tictactoe.py\*\* : jeu du morpion (Tic-Tac-Toe) jouable en console à deux joueurs

\- \*\*pierre-feuille-ciseaux.py\*\* : jeu Pierre-Feuille-Ciseaux contre l'ordinateur

\- \*\*analyse\_notes.py\*\* : analyse statistique d'un jeu de notes avec NumPy (moyenne, médiane, écart-type, etc.)



\## Technologies utilisées



\- Python

\- NumPy



\## Comment lancer un script



Ouvrir un terminal dans le dossier du projet, puis :



\\`\\`\\`

python nom\_du\_fichier.py

\\`\\`\\`
